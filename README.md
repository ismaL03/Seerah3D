# Sîra 3D

Carte 3D interactive pour les cours de **Sîra** (biographie du Prophète ﷺ), de **Hajj** et de **'Umra** : lieux, événements, itinéraires et étapes du pèlerinage, avec leurs sources.

> Projet en cours. Le dossier `prototype/` contient la première maquette (un seul fichier HTML à ouvrir dans un navigateur).

## Principes

- Aucune représentation humaine (ni le Prophète ﷺ, ni les Compagnons).
- Chaque fiche cite sa source et est validée par un enseignant avant publication.
- Les localisations discutées sont signalées comme telles.
